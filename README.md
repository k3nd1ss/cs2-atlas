# Атлас CS2

Статический сайт с 60 коллами и 311 раскидками на Mirage, Dust II и Inferno.

Откройте index.html в браузере. Сборка и сервер для просмотра не нужны. Для GitHub Pages поместите содержимое этой папки в корень репозитория и выберите публикацию из корня ветки в разделе Settings → Pages.

Игровые изображения лежат в assets. Источники указаны в карточках. Коллы могут иметь несколько зон, если план затрагивает несколько частей карты. У раскидок зона обозначает цель броска.
